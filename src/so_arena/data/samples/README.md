# Bundled data samples

Small samples used by offline tests and demos. Each section states the source and licence.

## `gsm8k_sample.jsonl` (GSM8K, MIT)

The first 50 problems of the GSM8K test split, verbatim (`question`, `answer`), from
https://github.com/openai/grade-school-math (`grade_school_math/data/test.jsonl`). Used by
`so_arena.domains.qa.GSM8K` when offline (ids `gsm8k-test-0000` to `gsm8k-test-0049`, the same
ids as the full download). The wrong answers of binary items are generated by so-arena; they are
not part of the dataset.

## `forecasting_synthetic.jsonl` (synthetic, MIT like so-arena)

Nine **made-up** forecasting questions about fictional places and clubs, written for so-arena, in
the schema of the Manifold Markets API (`"synthetic": true`, ids `synthetic-01` to `synthetic-09`,
plus a `probHistory` price history). Five resolved YES/NO, three pending (closing in 2031) and
one cancelled (N/A). They are not real markets, and no Manifold data is bundled: Manifold content
has no explicit open licence, so `ForecastingDomain` fetches real questions from the API into the
local cache instead.

Not bundled on purpose: MMLU, TruthfulQA and QuALITY are downloaded on demand; GPQA is gated and
its authors ask that examples not be posted online, so it must never be added here.
