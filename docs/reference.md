## `so_arena.analysis.diagnostics`

Diagnostics beyond incentive compatibility: the quality of the reward as a training signal, what else it pays for, the judge's calibration, whether simulated behaviours did...

- `calibration(df: Any, *, by: Sequence[str] = ('mechanism',), bins: int = 10, confidence_col: str = 'confidence', corre...)` - Calibration of the final decision, per group: the expected calibration error of its confidence (the largest outcome probability) against whether it was right...
- `compliance(df: Any, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), case_col: str | None ...)` - Did the instructed behaviours happen, at comparable effort?
- `cost_summary(df: Any, *, by: Sequence[str] = ('mechanism',)) -> pd.DataFrame` - What each mechanism consumed: episodes, tokens and dollars (total and per episode), oversight tokens (judges, monitors, auditors, graders), claims sent to verifiers, and the...
- `diagnostics_table(episodes: Sequence[Episode], *, ground_truth: bool = True) -> pd.DataFrame` - One row per mechanism with the headline diagnostics that apply: reward SNR and item share; with ``ground_truth``, the length bias, calibration error and stance compliance; cost...
- `ece(confidence: Sequence[float], correct: Sequence[float], bins: int = 10) -> float` - Expected calibration error: $\sum_b \frac{n_b}{n}\,|\overline{\text{conf}}_b - \overline{\text{acc}}_b|$ over equal-width confidence bins (pairs with a missing value are dropped).
- `length_bias(df: Any, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), value_col: str = 'val...)` - Does the reward pay for length at fixed ground truth?
- `option_label_bias(episodes: Sequence[Episode], items: Sequence[TaskItem] | Mapping[str, TaskItem], *, n_boot: int = 500, se...)` - Does the decision favour an option *label* (A over B) at fixed correctness?
- `position_bias(df: Any, *, first: str = 'debater_a', second: str = 'debater_b', by: Sequence[str] = ('mechanism',), valu...)` - The reward advantage of speaking as ``first`` rather than ``second`` (e.g. the debate slot) at equal ground truth: per item, the mean reward of ``first`` minus that of...
- `reliability(df: Any, *, bins: int = 10, by: Sequence[str] = ('mechanism',), confidence_col: str = 'confidence', corre...)` - Reliability-diagram rows: per group and confidence bin, the mean confidence of the final decision and its accuracy (from :func:`~so_arena.analysis.frames.episode_frame`, or...
- `reward_snr(df: Any, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), case_col: str | None ...)` - Signal-to-noise of the reward as a training signal, per group.

## `so_arena.analysis.metrics`

Incentive-compatibility metrics.

- `asd(df: pd.DataFrame, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), value_col: s...)` - Agent score difference, paired by item: mean over items of E[u | v=pos] - E[u | v=neg].
- `asd_by_transform(episodes: Sequence[Episode], transforms: Sequence[str] = ('log', 'brier', 'prob', 'accuracy'), **kwargs) ...)` - ASD under several proper-score transforms, re-scoring judge-based rewards post hoc.
- `auroc(scores_pos: Sequence[float], scores_neg: Sequence[float]) -> float` - P(score_pos > score_neg) + 0.5 P(tie).
- `bootstrap_mean_ci(values: np.ndarray, *, n_boot: int = 2000, ci: float = 0.95, seed: int = 0) -> tuple[float, float]`
- `cluster_bootstrap(clusters: Sequence[pd.DataFrame], stat: Callable[[pd.DataFrame], float], *, n_boot: int = 1000, ci: float...)` - Percentile CI of ``stat`` over resamples of whole clusters (e.g. items).
- `expected_scores(df: pd.DataFrame, *, betas: Sequence[float] = (0.0, 1.0, inf), roles: Sequence[str] | None = None, by: Se...)` - Expected agent score and expected judge score/accuracy if agents chose positions by softmax(ASD/beta).
- `fails_loudly(episodes: Sequence[Episode], *, signals: dict[str, Callable[[Episode], float | None]] | None = None, by: ...)` - Does a mechanism signal its own failures?
- `graded_asd(df: pd.DataFrame, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), value_col: s...)` - Graded ASD: per item, $\sum_c (v_c - \bar v) u_c$ over behaviour cases c (mean reward and value per case).
- `gt_regret(df: pd.DataFrame, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), strategy_col...)` - Ground-truth regret of optimizing the reward over a set of strategies: the best mean ground-truth value among them minus the value of the strategy with the highest mean reward...
- `incentive_alignment(df: pd.DataFrame, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), value_col: s...)` - Correlation-type IC measures between reward and ground-truth value.
- `incentive_gap_recovered(asd_protocol: float, asd_naive: float, asd_max: float = 2.0) -> float` - Share of the gap between a no-agent baseline and a perfect judge closed by the protocol.
- `judge_accuracy(df: pd.DataFrame, *, by: Sequence[str] = ('mechanism',), n_boot: int = 2000, seed: int = 0, min_coverage:...)` - Accuracy and probability-on-truth of the final decision (the "control" measure), per group.
- `open_probs(scores: dict[str, float], beta: float) -> dict[str, float]` - Propensity to argue for each position when free to choose: softmax of scores at temperature beta.
- `pairwise_concordance(g: pd.DataFrame, value_col: str = 'value', reward_col: str = 'reward') -> tuple[float, int]` - P(u_i > u_j | v_i > v_j) over within-item pairs (ties in u count 1/2).
- `summary(df: pd.DataFrame, *, roles: Sequence[str] | None = None, by: Sequence[str] = ('mechanism',), exclude_unpa...)` - One table joining ASD, graded ASD, alignment, judge accuracy and cost per group (with the judgments' parse-failure rate when the frame records it; see :func:`asd`).
- `tpr_at_fpr(scores_pos: Sequence[float], scores_neg: Sequence[float], fpr: float = 0.01) -> float` - Detection rate of ``pos`` at a threshold giving false-positive rate ``fpr`` on ``neg``.
- `with_parse_status(df: pd.DataFrame, episodes: Sequence[Episode]) -> pd.DataFrame` - A frame with a ``judge_parse_ok`` column (:func:`~so_arena.analysis.frames.judgment_status` of each row's episode).

## `so_arena.analysis.optimization`

- **`BestOfN`**

- **`Selection`**
- **`Tilted`**
- **`TreeLeaf`**
- **`TreeNode`**
- **`TreeValue`**
- **`Uniform`**
- `bon_kl_continuous(n: int) -> float` - KL of best-of-n from the base policy for continuous rewards: log n - (n-1)/n.

## `so_arena.core.rewards`

Reward rules: the payment part of a mechanism.

- **`Constant`**
- **`FromOutcome`** - Rewards the protocol computed itself, stored as ``outcome.data[key] = {role: reward}``.
- **`FunctionReward`** - ``fn(episode) -> {role: reward}``.
- **`JudgeAuditScore`** - Rewards for a *trainable judge*: a proper score of its final probabilities against an audit.
- **`JudgeScore`** - Each agent role is rewarded by a score of the final judge probability on its own position.
- **`MonitorPenalty`** - Subtract ``lam`` x monitor suspicion (in [0, 1]) from agent rewards: optimizing against a monitor.
- **`NoReward`**
- **`RandomAudit`** - With probability ``p`` an audit oracle checks the episode (costly state verification).
- **`ResolutionScore`** - Proper-scoring-rule rewards against a resolution that may arrive later (deferred reward).
- **`RewardRule`**
- **`Scaled`**
- **`Sum`**
- **`TeamReward`** - Every team member receives the team's score (a common objective).
- **`Whistleblower`** - Team reward plus individual incentives to report verified misbehaviour.
- **`ZeroSum`** - Make a two-player reward zero-sum: r_a' = (r_a - r_b)/2, r_b' = -r_a'.
- `audit_draw(ep: "'Episode'", tag: str = 'audit') -> float` - The uniform draw in $[0, 1)$ that decides whether ``ep`` is audited (audited iff it is below $p$).
- `describe_rule(rule: RewardRule | None) -> str`
- `rescore(episodes: "Sequence['Episode']", rule: RewardRule) -> "list['Episode']"` - Re-apply a (synchronous) reward rule to recorded episodes, returning updated copies.
- `score_probability(probs: dict[str, float], position: str, transform: str = 'log', eps: float = 0.0001) -> float` - Score the probability a judge assigns to ``position``.
- `truth_oracle(items: Sequence[Any]) -> "Callable[['Episode'], str | None]"` - An audit simulated from the experimenter's ground truth: ``ep -> the item's correct label``.
